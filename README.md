# Campus Lost-and-Found System

A Software Engineering course project developed by a team of four.

## Project Goal
Help students report lost or found items, search reports,
and claim their belongings.

## Planned Technologies
- PHP
- HTML and CSS
- MySQL
- XAMPP for local PHP development

## Development Model
Incremental development
